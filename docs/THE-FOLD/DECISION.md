# THE FOLD — Working product identity

**Status: owner-selected working title, not cleared for public launch.**

The Fold is a couples-first, family-extensible real-life RPG. People create their own private Fold, begin at Level 0, explore an interactive real-world map, complete shared or solo quests, earn achievements, and collect chapters in **The Adventure Book**.

Design metaphor: bringing loved ones into the fold, unfolding a map, folding down a memorable page. A Fold is a party, but each adult keeps independent consent, privacy and account ownership.

**Superseded name:** NEARLORE. Prior design documents under `docs/NEARLORE/` remain as archived development references, not current naming authority. Evergrove was a previous prototype, not the current product. Keep the user-facing product name as a provisional title until domain/trademark/confusability clearance is done.

**Development order:** working no-scroll map → first quest from Level 0 to Level 1 → saved chapter → private adult parties → opt-in foreground location → separate verified member-owned ANEVUM Creator V1 submission by display name Devon. No production deployment or public release implied. See Lab issue anevum/anevum-web#349 and game issue #6.

**Safety defaults:** no GPS required, no background tracking, no minor precise location, no fabricated collaborators, no automatic location-history collection or reward for distance/speed. A prototype's local storage is neither authenticated nor backed up.
